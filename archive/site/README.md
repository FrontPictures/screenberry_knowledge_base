# Help Screenberry

## Запуск локально

Требования: Node.js `22.13.0` или новее.

```bash
git clone <URL-репозитория>
cd help.screenberry.com
corepack enable
corepack use pnpm@latest-11
pnpm install
pnpm dev
```

После запуска откройте [http://localhost:3000](http://localhost:3000).
