# Creating and Managing Playlists

**Playlists** are used to organize media items for playback in the **Media Player** widget. Folders can be used to organize playlists.

## Adding Playlists

To create a new playlist, either right-click an empty area of the **Navigation Pane** or click the **Add** button <img alt="Add" src="/images/media-playback/static/add.png" width={23} height={23} loading="lazy" /> on the bottom toolbar and select **Add Playlist** from the dropdown menu.

<img alt="Adding Playlists" src="/images/media-playback/animation/Adding-Playlists.gif" width={800} height={436} loading="lazy" />

To add a new playlist to an existing folder, select the folder and click the **Add** button <img alt="Add" src="/images/media-playback/static/add.png" width={23} height={23} loading="lazy" /> on the bottom toolbar, or right-click the folder name and select **Add Playlist** from the dropdown menu.

To show/hide a folder’s contents, press the arrow icons next to the folder icon.

<img alt="Adding Playlists2" src="/images/media-playback/animation/Adding-Playlists2.gif" width={800} height={436} loading="lazy" />

## Renaming Playlists

When you create playlists, it’s helpful to name them descriptively so they can be identified easily. To rename it, right-click on a playlist, select **Rename** from the dropdown menu, and enter a new name in the opened dialog box.

<img alt="Renaming Playlists" src="/images/media-playback/animation/Renaming-Playlists.gif" width={800} height={372} loading="lazy" />

## Deleting Playlists

To delete a playlist, either right-click on its name, and select **Delete** from the dropdown menu, or select its name and click the **Delete** button <img alt="Trash" src="/images/media-playback/static/trash.png" width={16} height={16} loading="lazy" /> in the bottom toolbar of the **Navigation Pane**.

<img alt="Deleting Playlists" src="/images/media-playback/animation/Deleting-Playlists.gif" width={800} height={372} loading="lazy" />

## Arranging Playlists

To navigate the playlists and timelines list, use the **`Up`** and **`Down`** arrow keys. To expand or collapse the contents of a folder, click on the arrow icon next to the folder icon.

To change the order of playlists, timelines, and folders, either right-click on the name and select **Move Up** (**`Ctrl`** + **`Up`**) or **Move Down** (**`Ctrl`** + **`Down`**) from the dropdown menu, or drag and drop them into the list. A playlist can be moved into a folder by dragging it over the name of a folder or its contents.

<img alt="Arranging Playlists" src="/images/media-playback/animation/Arranging-Playlists.gif" width={800} height={372} loading="lazy" />

## Playlist Settings and Indication

<img alt="Indication Playlists" src="/images/media-playback/animation/Indication-Playlists.gif" width={464} height={76} loading="lazy" />

1. **Locking and Unlocking** a playlist to prevent accidental modifications. A locked playlist cannot be further modified, while an unlocked one can be edited.
2. **Playback Control with Presentation Clicker**. The playback of playlists may be controlled by a presentation clicker. This toggle enables and disables this function. For more information, see [Playlist Playback Control with Presentation Clicker](playlists-playback#playback-control-with-presentation-clicker).
3. **MIDI/Keyboard Events Mapping**. Individual media items in playlists can be mapped to start playback on MIDI/Keyboard events. This toggle changes the state of a playlist between listening to MIDI/Keyboard events and ignoring them. For more information, see [Mapping Media Item to MIDI/Keyboard Event](media-item-properties#mapping-a-media-item-to-a-midikeyboard-event).
4. **Listening to the Timecode** toggle changes the state of a playlist between listening to the timecode and ignoring it.
5. **Number of Media Items** currently added to the playlist.

### Playback Indication

When a playlist is currently being played, paused, or stopped, the corresponding indicators appear next to the playlist name. Whenever the currently active playlist is part of a folder, and the contents of the folder have been collapsed, these indicators replace the folder icon.
