# Managing Media Library Folders

## Adding Folders

To add a folder:

1. Click the **Create Folder** button <img alt="Folder" src="/images/organizing-media/static/folder.png" width={30} height={30} loading="lazy" /> at the bottom of the folders tree area, or right-click in a folder contents area and select **Add Folder** in the drop-down menu.
2. Enter the folder name and click the **OK** button.

<img alt="Adding Media Library Folders" src="/images/organizing-media/animation/Adding-Media-Library-Folders.gif" width={800} height={316} loading="lazy" />

## Deleting Folders

To delete a folder, right-click on the folder name or in a folder contents area and select Remove Folder in the drop-down menu, or click on the **Delete** button <img alt="Delete" src="/images/organizing-media/static/delete.png" width={30} height={30} loading="lazy" />.

<img alt="Deleting Media Library Folders" src="/images/organizing-media/animation/Deleting-Media-Library-Folders.gif" width={800} height={276} loading="lazy" />

## Renaming Folders

To rename a folder:

1. Right-click on the folder name and select **Rename Folder** in the drop-down menu.
2. Enter a new folder name and click the **OK** button.

<img alt="Renaming Media Library Folders" src="/images/organizing-media/animation/Renaming-Media-Library-Folders.gif" width={800} height={244} loading="lazy" />

## Arranging Folders

To arrange folders, drag and drop folder names in the folders tree area.

<img alt="Arranging Media Library Folders" src="/images/organizing-media/animation/Arranging-Media-Library-Folders.gif" width={800} height={244} loading="lazy" />
