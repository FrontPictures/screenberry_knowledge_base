# Node Parameters and Settings

## Node Parameters (Pins)

In Screenberry, every node has a set of parameters. These parameters are represented by pins on the nodes. The flow of data, actions, or messages between nodes is established by creating links between the pins of corresponding parameters.

<img alt="Node Parameters Pins" src="/images/working-with-nodes/animation/Node-Parameters-Pins.gif" width={800} height={344} loading="lazy" />

**Data** (gray pin <img alt="Grey Pin" src="/images/working-with-nodes/static/grey-pin.png" width={21} height={21} loading="lazy" />  ) parameter contains simple data (number, string, timecode) or a pointer to Screenberry internal resources (i.e. image).

**SmartLink** (blue pin <img alt="Blue Pin" src="/images/working-with-nodes/static/blue-pin.png" width={21} height={21} loading="lazy" /> ) establishes a transaction of a process between linked nodes.

**Action** (orange pin <img alt="Orange Pin" src="/images/working-with-nodes/static/orange-pin.png" width={21} height={21} loading="lazy" /> ) supports the creation of multiple links to one input. The value of each resulting frame will be determined using logical OR for all input values.

**Messages** (pink pin <img alt="Pink Pin" src="/images/working-with-nodes/static/pink-pin.png" width={21} height={21} loading="lazy" /> ) also enables the creation of multiple links to one input. All incoming messages will be queued on the input.

<img alt="Node Parameters Example" src="/images/working-with-nodes/static/Node-Parameters-Example.gif" width={800} height={260} loading="lazy" />

## Node Settings

Selecting the node will open its **Settings** panel where node parameters can be edited.

<img alt="Node Settings" src="/images/working-with-nodes/animation/Node-Settings.gif" width={800} height={428} loading="lazy" />

The change of the node parameter value in the **Settings** panel is indicated by the button <img alt="Redoarrow 1" src="/images/working-with-nodes/static/redoarrow-1.png" width={17} height={16} loading="lazy" /> next to the parameter value field. Clicking on this button restores the default parameter value.

<img alt="Restore Node Settings" src="/images/working-with-nodes/animation/Restore-Node-Settings.gif" width={352} height={284} loading="lazy" />

### Settings of Multiple Selected Nodes

When more than one node is selected, only the parameters common to all selected nodes are displayed in the **Settings** panel and can be edited. Additionally, information regarding the number of nodes of each type within the selection will be displayed on the buttons at the top of the **Settings** panel. Click a button with a number to have only the nodes of that type remain in the current selection.

<img alt="Selecting Nodes by Type" src="/images/working-with-nodes/animation/Selecting-Nodes-by-Type.gif" width={800} height={424} loading="lazy" />

## Hiding/Showing Individual Node Parameters

To hide a parameter, right-click on the parameter name and select **Hide** from the dropdown menu. To display hidden parameters, click **Show** in the **Hidden parameters** field. The parameters with a hidden status are displayed in italics. To unhide a parameter, right-click on the parameter name and select **Show** from the dropdown menu. To stop displaying hidden parameters, click **Hide** in the **Hidden parameters** field.

<img alt="Hiding and Showing Individual Node Parameters" src="/images/working-with-nodes/animation/Hiding-Showing-Node-Parameters.gif" width={400} height={344} loading="lazy" />

> **Note:** Less frequently used and more advanced parameters for some nodes are hidden by default.

## Hiding/Showing Node Pins

In the **Settings** panel, left-clicking on the dot to the left of the parameter name toggles between displaying and hiding the corresponding parameter pin on the node. A blue dot <img alt="Blue Dot" src="/images/working-with-nodes/static/bluedot-1.png" width={14} height={14} loading="lazy" /> indicates that the parameter pin is displayed, and a gray dot <img alt="Grey Dot" src="/images/working-with-nodes/static/greydot-1.png" width={14} height={14} loading="lazy" /> indicates that it is hidden.

<img alt="Hiding Showing Node Pins" src="/images/working-with-nodes/animation/Hiding-Showing-Node-Pins.gif" width={800} height={320} loading="lazy" />

When a parameter pin with an established link becomes hidden, this link will remain active and be displayed as a dimmed straight line.

<img alt="Dimmed Link" src="/images/working-with-nodes/animation/Dimmed-Link.gif" width={800} height={296} loading="lazy" />
