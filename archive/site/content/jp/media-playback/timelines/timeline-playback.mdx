# タイムラインの再生

タイムライン再生を開始するには、次のいずれかの方法を使用します：

- 現在の再生位置から再生を開始するには、**Play**<img alt="Play1" src="/images/media-playback/static/play1.png" width={24} height={24} loading="lazy" />ボタンをクリックします。
- タイムライントラック上のメディアアイテムを選択し、**Play Selected Item**<img alt="Play" src="/images/media-playback/static/play.png" width={24} height={24} loading="lazy" />ボタンをクリックする（または **`Ctrl`** + **`スペースバー`** を押す）と、そのアイテムから始まるタイムラインの再生が開始されます。
- マウスカーソルをオレンジ色の**再生**![Altplay](/images/media-playback/static/altplay.png)シンボルに変えるために、タイムライントラック上で **`Alt`** キーを押しながらマウスをホバーさせてください。その後、メディアアイテムまたは再生を開始したいマーカーをクリックしてください。
- もしタイムラインが以前に一時停止されていた場合、**`スペースバー`** を押すと、現在の再生ヘッド位置から再生が再開されます。

タイムラインの再生を一時停止するには、以下の方法があります。

- 現在の再生ヘッドの位置で再生を一時停止するには、**Pause**<img alt="Pause" src="/images/media-playback/static/pause.png" width={24} height={24} loading="lazy" />ボタンをクリックします。
- **`スペースバー`** を押して再生を一時停止または再開します。このキーボードショートカットはトグルとして機能し、押すたびにタイムラインの再生と一時停止が切り替わります。

タイムラインの再生を停止するには、**Stop**<img alt="Stop" src="/images/media-playback/static/stop.png" width={24} height={24} loading="lazy" />ボタンをクリックして再生を完全に停止します。この操作により、再生ヘッドの位置もタイムラインの最初にリセットされます。

さらに、**再生制御**バーには再生制御のロック/アンロックを切り替える**Lock/Unlock Playback Controls**<img alt="Lock" src="/images/media-playback/static/lock.png" width={24} height={24} loading="lazy" />トグルボタンと、アクティブなアイテムを表示する**Reveal Active Item**<img alt="Reveal Icon" src="/images/media-playback/static/reveal-icon.png" width={23} height={23} loading="lazy" />ボタンがあります。

タイムラインの再生状態を誤って操作してしまうのを防ぐには、**Lock/Unlock Playback Controls**<img alt="Lock" src="/images/media-playback/static/lock.png" width={24} height={24} loading="lazy" />トグルボタンを使用します。タイムラインがロックされている場合、すべての Play、Pause、Stop ボタンは無効になります。再びアンロックするには、**Lock/Unlock Playback Controls**<img alt="Lock" src="/images/media-playback/static/lock.png" width={24} height={24} loading="lazy" />トグルボタンを再度クリックしてください。

現在再生中のメディアアイテムを検索するには、**Reveal Active Item**<img alt="Reveal Icon" src="/images/media-playback/static/reveal-icon.png" width={23} height={23} loading="lazy" />ボタンをクリックしてください。これにより表示がアクティブなタイムラインに切り替わり、現在再生中のアイテムの位置に自動的にスクロールされ、アイテムが目立つようにハイライトされます。
