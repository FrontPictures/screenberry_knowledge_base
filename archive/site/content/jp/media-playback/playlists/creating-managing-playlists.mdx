# プレイリストの作成と編集

**プレイリスト**は、**Media Player**ウィジェットで再生するためにメディアアイテムを整理するために使用されます。フォルダを使用してプレイリストを整理することもできます。

## プレイリストの追加

新しいプレイリストを作成するには、**ナビゲーションパネル**の空白のエリアで右クリックするか、下部のツールバーの**Add**<img alt="Add" src="/images/media-playback/static/add.png" width={23} height={23} loading="lazy" />ボタンをクリックし、ドロップダウンメニューから**Add Playlist**を選択します。

<img alt="Adding Playlists" src="/images/media-playback/animation/Adding-Playlists.gif" width={800} height={436} loading="lazy" />

既存のフォルダに新しいプレイリストを追加するには、フォルダを選択し、下部ツールバーの**Add**<img alt="Add" src="/images/media-playback/static/add.png" width={23} height={23} loading="lazy" />ボタンをクリックするか、フォルダ名を右クリックしてドロップダウンメニューから**Add Playlist**を選択してください。

フォルダの内容を表示/非表示にするには、フォルダアイコンの隣にある矢印アイコンを押してください。

<img alt="Adding Playlists2" src="/images/media-playback/animation/Adding-Playlists2.gif" width={800} height={436} loading="lazy" />

## プレイリスト名の変更

プレイリストを作成する際は、説明的な名前を付けると簡単に探し出すことができます。プレイリストの名前を変更するには、プレイリストを右クリックし、ドロップダウンメニューから **Rename** を選択し、表示されるダイアログボックスに新しい名前を入力してください。

<img alt="Renaming Playlists" src="/images/media-playback/animation/Renaming-Playlists.gif" width={800} height={372} loading="lazy" />

## プレイリストの削除

プレイリストを削除するには、その名前を右クリックしてドロップダウンメニューから**Delete**を選択するか、名前を選択して**ナビゲーションパネル**の下部ツールバーにある**Delete**<img alt="Trash" src="/images/media-playback/static/trash.png" width={16} height={16} loading="lazy" />ボタンをクリックします。

<img alt="Deleting Playlists" src="/images/media-playback/animation/Deleting-Playlists.gif" width={800} height={372} loading="lazy" />

## プレイリストの整理

プレイリストとタイムラインのリスト内を移動するには、**`↑`** または **`↓`** の矢印キーを使用してください。フォルダのコンテンツを展開または折りたたむには、フォルダアイコンの隣にある矢印アイコンをクリックしてください。

プレイリスト、タイムライン、およびフォルダの順序を変更するには、名前を右クリックし、ドロップダウンメニューから**上に移動**（**`Ctrl`** + **`↑`**）または**下に移動**（**`Ctrl`** + **`↓`**）を選択するか、それらをリストにドラッグアンドドロップしてください。プレイリストは、フォルダの名前またはそのコンテンツの上にドラッグすることで、フォルダ内に移動することができます。

<img alt="Arranging Playlists" src="/images/media-playback/animation/Arranging-Playlists.gif" width={800} height={372} loading="lazy" />

## プレイリストの設定と状態表示

<img alt="Indication Playlists" src="/images/media-playback/animation/Indication-Playlists.gif" width={464} height={76} loading="lazy" />

1. **ロックとアンロック：** 誤操作を防ぐためにプレイリストをロックすることができます。ロックされたプレイリストは編集できませんが、アンロックすることでまた編集できるようになります。
2. **プレゼンテーションクリッカーによる再生制御：** プレイリストの再生はプレゼンテーションクリッカーで制御することができます。このトグルを使用して、この機能を有効または無効にすることができます。詳細については、[プレゼンテーションクリッカーによるプレイリストの再生制御](playlists-playback#プレゼンテーションクリッカーでの再生制御) を参照してください。
3. **MIDI/キーボードイベントのマッピング：** プレイリスト内の各メディアアイテムは、MIDI/キーボードイベントで再生を開始するようにマッピングすることができます。このトグルを使用して、プレイリストのMIDI/キーボードイベントの受信または無視の状態を切り替えることができます。詳細については、[メディアアイテムをMIDI/キーボードイベントにマッピングする](media-item-properties#メディアアイテムをmidiキーボードイベントにマッピングする) を参照してください。
4. **タイムコードの受信：** このトグルを使用して、プレイリストのタイムコードの受信または無視の状態を切り替えることができます。
5. **メディアアイテムの数：** 現在プレイリストに追加されているメディアアイテムの数が表示されます。

### プレイリストの状態表示

プレイリストが現在再生中、一時停止中、または停止中の場合、対応するアイコンがプレイリスト名の横に表示されます。現在アクティブなプレイリストがフォルダの一部であり、フォルダの内容が折りたたまれている場合、これらのアイコンはフォルダアイコンに置き換えられます。
