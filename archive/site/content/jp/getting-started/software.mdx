# ソフトウェアのインストール

**Screenberry Setup 3.2.X.exe**ファイルを実行して、**Screenberry Setup Wizard**を起動します。画面に表示される指示に従ってください。

1. **Screenberry Setup Wizard**を起動します。

![Install1](/images/getting-started/static/install1.png)

2. **Screenberry Server**をインストールするフォルダを選択し、**Next**ボタンをクリックします。

![Install2](/images/getting-started/static/Install2.png)

3. インストールしたいコンポーネントを選択して、**Next**ボタンをクリックします。

![Install3](/images/getting-started/static/install3.png)

4. **End User Licence Agreement**に同意したら、**Next**ボタンをクリックします。

![Install4](/images/getting-started/static/install4.png)

5. **Start Menu shortcuts** を表示したい場所を選択したら、**Next**ボタンをクリックします。

![Install5](/images/getting-started/static/Install5.png)

![Install6](/images/getting-started/static/install6.png)

6. **Install**ボタンをクリックし、**Screenberry**がインストールされるのを待ちます。インストールが完了したら、**Finish**ボタンをクリックして終了します。

![Install7](/images/getting-started/static/install7.png)

![Install8](/images/getting-started/static/install8.png)

## Screenberryの起動

メディアサーバーに接続するには：

1. メディアサーバーとなるPCで、**Screenberry Server**アプリケーションを起動します。

![Run1](/images/getting-started/static/run1.png)

2. 操作用端末となるPCで、**Screenberry Panel**アプリケーションを起動します。

![Run2](/images/getting-started/static/run2.png)

3. **ウェルカム**ウィンドウ内で、利用可能なメディアサーバーを選択し**Connect**ボタンをクリックします。

![Connect](/images/getting-started/static/connect.png)

**Screenberry Server**を初めて実行する際には、*Windowsのセキュリティ警告*ダイアログが表示され、アプリの一部の機能が*Windowsのファイヤーウォール*機能によってブロックされる可能性があることが通知されます。このネットワーク上で**Screenberry Server**が通信するために、*プライベート ネットワーク*と*パブリック ネットワーク*の両方のチェックボックスをオンにしてください。

![WIndows Alert](/images/getting-started/static/WIndows-Alert.png)
