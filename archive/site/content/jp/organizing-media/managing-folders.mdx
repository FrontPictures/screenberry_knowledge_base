# Media Libraryフォルダの操作

## フォルダの追加

フォルダを追加するには：

1. フォルダツリーエリアの下部にある**Create Folder**<img alt="Folder" src="/images/organizing-media/static/folder.png" width={30} height={30} loading="lazy" />ボタンをクリックするか、フォルダのコンテンツエリアで右クリックし、ドロップダウンメニューから**Add Folder**を選択します。
2. フォルダ名を入力し、**OK**ボタンをクリックします。

<img alt="Adding Media Library Folders" src="/images/organizing-media/animation/Adding-Media-Library-Folders.gif" width={800} height={316} loading="lazy" />

## フォルダの削除

フォルダを削除するには、フォルダ名を右クリックするか、フォルダのコンテンツエリアで右クリックし、ドロップダウンメニューから**Remove Folder**を選択するか**Delete**<img alt="Delete" src="/images/organizing-media/static/delete.png" width={30} height={30} loading="lazy" />ボタンをクリックしてください。

<img alt="Deleting Media Library Folders" src="/images/organizing-media/animation/Deleting-Media-Library-Folders.gif" width={800} height={276} loading="lazy" />

## フォルダ名の変更

フォルダの名前を変更するには以下の手順を実行してください：

1. フォルダ名を右クリックし、ドロップダウンメニューから**Rename Folder**を選択します。
2. 新しいフォルダ名を入力し、**OK**ボタンをクリックします。

<img alt="Renaming Media Library Folders" src="/images/organizing-media/animation/Renaming-Media-Library-Folders.gif" width={800} height={244} loading="lazy" />

## フォルダの整理

フォルダを整理するには、フォルダツリーエリアでフォルダ名をドラッグアンドドロップしてください。

<img alt="Arranging Media Library Folders" src="/images/organizing-media/animation/Arranging-Media-Library-Folders.gif" width={800} height={244} loading="lazy" />
