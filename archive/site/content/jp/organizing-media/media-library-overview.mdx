# Media Libraryの概要

**Media Library**（メディアライブラリー）ウィジェットでは、ユーザーがサーバーに保存されているメディアコンテンツをアップロード、表示、管理することができます。Screenberry Panelのメインメニューから、**Window** > **Media Library** を選択して追加することができます。

## Media Library の画面構成

![Media Library View](/images/organizing-media/static/media-library-view.png)

**Media library**の画面構成： *1 - フォルダツリー、2 - コンテンツエリア、3 - メディアライブラリ情報とコントロールバー。*

**Media**フォルダはデフォルトのルートフォルダであり、削除することはできません。新しいフォルダはすべて**Media**フォルダ内に作成されます。

## Media Library の操作

![Media Library Controls](/images/organizing-media/static/media-library-controls.png)

1. **Interrupt**ボタンは、アップロード/変換処理を停止します。
2. **Uploading**の進捗バーは、サーバーにアップロードされたメディアアイテムの割合と、既にアップロードされたファイルの数/アップロード中の総ファイル数を表示します。
3. **Converting**の進捗バーは、各メディアファイルの変換の進捗率を表示します。
4. メディアアイテムの**Search**ボックス。
5. **Disk Space Usage Information**は、使用済みスペース/サーバー内蔵ドライブの総容量を表示します。
6. **Thumbnail Size Sliders**は、メディアファイルのサムネイルのスケールと幅を調整します。
7. **Refresh**ボタンは、メディアライブラリに表示されるコンテンツを更新します。
