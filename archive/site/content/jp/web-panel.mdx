# Web操作画面

## 概要

Web操作画面は、HTML 5で動作するプラットフォーム非依存のウェブインターフェースを提供し、複数のユーザーがコンピュータ、タブレット、またはスマートフォンからウェブブラウザを介して同時にScreenberry Serverを操作できるようにします。

## Web操作画面へのアクセス

以下の手順でWeb操作画面にアクセスしてください：

1. **Node Graph**に、**WebServer**ノードを追加します。ノードのSettingsパネルで**Port**がデフォルトの8081に設定されていることを確認してください。ポート番号8081が既に使用されている場合は、別のポート番号を選択することもできます。
2. Screenberry Serverと同じPCからWeb操作画面にアクセスする場合は、ウェブブラウザでURL [http://127.0.0.1:8081](http://127.0.0.1:8081/)（または [http://localhost:8081](http://localhost:8081/)）を入力してください。無線端末や同じLAN内の別のPCなどからアクセスする場合は、Screenberry ServerのPCに関連付けられているIPアドレスのいずれかを入力することができます。例えば、URLは[http://192.168.31.218:8081](http://192.168.31.218:8081/)のようになります。

<img alt="Adding Web Panel" src="/images/web-panel/animation/Adding-Web-Panel.gif" width={800} height={564} loading="lazy" />

> **メモ：** Web操作画面では、Screenberryで現在作成されているメディアプレーヤー、プレイリスト、およびウィジェットにアクセスできます。

> **メモ：** Screenberryバージョン2.8.xの一部のビルドには既知の問題があり、新しく作成されたScreenberryプロジェクトの*Resources*フォルダにWebサーバーコンポーネントがコピーされません。上記の手順を完了した後、空のページが表示される場合は、[このアーカイブ](../downloads/Web-Panel-Components.zip)からファイルをプロジェクトの*Resources/webServer*フォルダに手動でコピーしてください。


## 映像の再生

Web操作画面は、Screenberryで作成された**Media Player**の映像再生とプレイリストの制御を提供します。

### プレイリストの選択

以下の手順で、目的のプレイリストにアクセスしてください：

1. 左上の**Screenberry Web Panel**メニュー<img alt="Burgmenu" src="/images/web-panel/static/burgmenu.png" width={24} height={24} loading="lazy" />ボタンをクリックし、**Media Player**を選択します。
2. 右下隅にある**Settings**<img alt="Settings Button" src="/images/web-panel/static/settings_button.png" width={24} height={24} loading="lazy" />ボタンをクリックして、右のサイドバーを開きます。
3. ドロップダウンメニューで**Media Player**を選択します。
4. ドロップダウンメニューでプレイリストを選択します。

<img alt="Playlist Selection" src="/images/web-panel/animation/Playlist-Selection.gif" width={800} height={474} loading="lazy" />

### 再生制御

![Web Panel Controls280](/images/web-panel/static/web-panel-controls280.png)

1. <img alt="Play Selected" src="/images/web-panel/static/play-selected.png" width={24} height={24} loading="lazy" /> **Play Selected Item**ボタンで、選択されたメディアアイテムの再生を開始します。
2. <img alt="Play" src="/images/web-panel/static/play.png" width={24} height={24} loading="lazy" /> **Play**ボタンで、現在の再生ヘッドの位置から再生を開始します。
3. <img alt="Pause" src="/images/web-panel/static/pause.png" width={24} height={24} loading="lazy" /> **Pause**ボタンで、現在の再生ヘッドの位置で再生を一時停止します。
4. <img alt="Stop" src="/images/web-panel/static/stop.png" width={24} height={24} loading="lazy" /> **Stop**ボタンで、再生を終了します。
5. <img alt="Rew" src="/images/web-panel/static/rew.png" width={24} height={24} loading="lazy" /> **Previous Item**ボタンで、プレイリスト内の一つ前のメディアアイテムにジャンプします。
6. <img alt="Fwd" src="/images/web-panel/static/fwd.png" width={24} height={24} loading="lazy" /> **Next Item**ボタンで、プレイリスト内の次のメディアアイテムにジャンプします。
7. <img alt="Volume" src="/images/web-panel/static/volume.png" width={24} height={24} loading="lazy" /> **Volume Control**ボタンで、**Media Player**自体の音量を調整します。

### メディアアイテムの再生

プレイリスト内のメディアアイテムを再生するには、以下のいずれかの方法を使用します：

- **Play**<img alt="Play" src="/images/web-panel/static/play.png" width={24} height={24} loading="lazy" />ボタンで、現在の再生ヘッドの位置から再生を開始します。
- プレイリストの中からメディアアイテムを選択し、**Play Selected Item**<img alt="Play Selected" src="/images/web-panel/static/play-selected.png" width={24} height={24} loading="lazy" />ボタンで再生を開始します。

<img alt="Media Items Playback" src="/images/web-panel/animation/Media-Items-Playback.gif" width={800} height={515} loading="lazy" />

### メディアアイテムの設定

メディアアイテムの設定にアクセスするには、メディアアイテムを選択し、右下隅にある**Settings** <img alt="Settings Button" src="/images/web-panel/static/settings_button.png" width={24} height={24} loading="lazy" /> ボタンを押してください。

以下のメディアアイテムの設定が編集可能です：

- **Title**： メディアアイテムの名前を変更します。
- **Fade In**： メディアアイテムのフェードイン時間を秒単位で定義します（前のメディアアイテムとのクロスフェード）。
- **Pause on First Frame** / **Pause on Last Frame**： メディアアイテムの再生を最初のフレームまたは最後のフレームで一時停止させるかどうかを設定します。
- **Loops**と**Infinite Loop**： メディアアイテムをループ再生させるかどうかを設定します。
- **Volume**： 選択したメディアアイテムの音量を調整します。

<img alt="Media Item Settings" src="/images/web-panel/animation/Media-Item-Settings.gif" width={800} height={466} loading="lazy" />

### プレイリストの管理

プレイリストを管理するには、右下の **Settings** <img alt="Settings Button" src="/images/web-panel/static/settings_button.png" width={24} height={24} loading="lazy" /> ボタンをクリックして、右サイドバーを開き、次にプレイリストのドロップダウンメニューをクリックします。以下の操作を行うことができます。

- 新しいプレイリストを追加するには、**Add New Playlist**ボタンをクリックします。
- プレイリストの名前を変更するには、プレイリスト名の横にある**編集**アイコン<img alt="Edit" src="/images/web-panel/static/edit.png" width={24} height={24} loading="lazy" />をクリックし、表示されたダイアログボックスに新しい名前を入力してください。
- プレイリストを削除するには、プレイリスト名の横にある**ゴミ箱**アイコン<img alt="Trash" src="/images/web-panel/static/trash.png" width={24} height={24} loading="lazy" />をクリックしてください。

<img alt="Managing Playlists" src="/images/web-panel/animation/Managing-Playlists.gif" width={1304} height={760} loading="lazy" />

### プレイリスト内のメディアアイテムの整理

メディアアイテムをプレイリストで整理するには、**Edit**フローティング![Edit Big](/images/web-panel/static/edit-big.png)ボタンをクリックします。以下の操作を行うことができます：

- メディアアイテムを追加するには、プレイリストが空の場合は![Plus](/images/web-panel/static/plus.png)ボタンをクリックします。特定のメディアアイテムの場合は<img alt="Plus Icon" src="/images/web-panel/static/plus-icon.png" width={29} height={29} loading="lazy" />アイコンをクリックしてから追加するメディアアイテムを選択します。開いた**Media Library**ウィジェットでメディアアイテムを選択し、**Add**![Add](/images/web-panel/static/add.png)ボタンを押します。
- メディアアイテムを削除するには、メディアアイテム上の<img alt="X Icon" src="/images/web-panel/static/x-icon.png" width={29} height={29} loading="lazy" />アイコンをクリックしてください。
- メディアアイテムの順序を変更するには、メディアアイテムを希望する位置にドラッグしてください。

プレイリストの編集が終わったら、再び**Edit**フローティング![Edit Big](/images/web-panel/static/edit-big.png)ボタンをクリックして編集モードを終了してください。

<img alt="Organizing Media Items In Playlists" src="/images/web-panel/animation/Organizing-Media-Items-in-Playlists.gif" width={800} height={494} loading="lazy" />

## ウィジェットの操作

Web操作画面では、Screenberryに追加されたウィジェットにアクセスできます。

以下の手順で、目的のウィジェットにアクセスしてください。

1. 左上隅にある**Screenberry Web Panel**ボタンをクリックし、**Widget**を選択します。
2. ドロップダウンメニューから**Widget**を選択します。

<img alt="Working With Widgets" src="/images/web-panel/animation/Working-with-Widgets.gif" width={800} height={494} loading="lazy" />
