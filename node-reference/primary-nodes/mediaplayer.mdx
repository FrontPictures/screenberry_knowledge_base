# Media Player

The **Media Player** node creates a media player that provides control over the playlists and timelines playback. Its output **Image** parameter can be connected to any node capable of receiving an input image. The **Media Player** node can also output **Audio**, **Subtitles**, and **Timecode** parameters.

<img alt="Media Playback Node Graph" src="/images/node-references/animation/MediaPlayer.gif" width={800} height={640} loading="lazy" />

For detailed information on managing media playback with the help of the **Media Player** widget, see [Media Playback](../../../media-playback/media-player/media-player-overview).

May slightly adjust the playback speed to provide smoother video playback. For example, if the **Canvas** frame rate is set to 29.97 FPS and a source video is 30 FPS, the video will play at 29.97 FPS to avoid frame skipping (at an initial speed of 99.9%). The playback speed (pitch) of audio tracks will be continuously updated to maintain audio-video synchronization.<br />• **Sync to Audio Device Time** – synchronization by source audio. The audio track of the first media item is played at 100% speed, while video frames are skipped/doubled for synchronization.
