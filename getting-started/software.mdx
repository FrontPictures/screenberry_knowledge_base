# Software Installation

Run the **Screenberry Setup 3.2.X.exe** file to open the **Screenberry Setup Wizard**, and follow the on-screen instructions.

1. Launch the **Screenberry Setup Wizard.**

![Install1](/images/getting-started/static/install1.png)

2. Choose a folder in which to install the **Screenberry Server**, and press the **Next** button.

![Install2](/images/getting-started/static/Install2.png)

3. Select the components you want to install and press the **Next** button.

![Install3](/images/getting-started/static/install3.png)

4. Accept the **End User Licence Agreement**, and press the **Next** button.

![Install4](/images/getting-started/static/install4.png)

5. Select **Start Menu Shortcuts** and where they should appear, then press the **Next** button.

![Install5](/images/getting-started/static/Install5.png)

![Install6](/images/getting-started/static/install6.png)

6. Press the **Install** button, and wait for **Screenberry** to be installed. When the installation is complete, press the **Finish** button to exit.

![Install7](/images/getting-started/static/install7.png)

![Install8](/images/getting-started/static/install8.png)

## Running Screenberry

To connect to the Media Server:

1. Launch the **Screenberry Server** application on the Media Server computer.

![Run1](/images/getting-started/static/run1.png)

2. Launch the **Screenberry Control Panel** on the Operator Workstation.

![Run2](/images/getting-started/static/run2.png)

3. In the **Welcome** window, select an available media server and press **Connect**.

![Connect](/images/getting-started/static/connect.png)

When running the **Screenberry Server** for the first time, the *Windows Security Alert* dialog window will appear notifying that some features of the app can be blocked by *Windows Firewall*. Check both the *Private Network*s and *Public Networks* checkboxes to allow **Screenberry Server** to communicate on these networks.

![WIndows Alert](/images/getting-started/static/WIndows-Alert.png)
