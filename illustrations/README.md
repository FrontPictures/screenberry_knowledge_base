# User Guide illustration briefs

Text-only, optional editorial briefs. Each YAML file identifies its source document, language, body hash and placement. Fields: title, caption, show, status, placement and source provenance. No images are stored here. These records must not enter product-answer retrieval. Imported briefs require review and may be removed if prose is sufficient.

See [the workflow](../docs/TEXT-AND-ILLUSTRATIONS.md).
