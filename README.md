# Screenberry Knowledge Base

Текстовая база знаний для AI и подготовки User Guide. Содержит все **174 статьи** исходного руководства: **90 en и 84 jp**. Текст, заголовки и примеры кода сохранены; изображения вынесены в отдельные задания для будущего руководства.

**GIF, скриншоты, видео, шрифты и ZIP-примеры в эту папку не входят.** Исходный сайт и его ресурсы остаются в исходном проекте.

Начните с [каталога статей](catalog/README.md), [правил работы со скриншотами](docs/TEXT-AND-ILLUSTRATIONS.md) и [текущего отчёта](docs/MIGRATION.md).

Добавлен отдельный [справочник реализации по исходному коду](implementation/3.5.0-beta-build2422/README.md): **50 фактов на английском в 15 темах**, проверенных по конкретным участкам исходников **3.5.0 beta, source build 2422**. У каждого факта есть границы вывода, номера строк и SHA-256 файлов. Это статическая проверка реализации; runtime не проверен, ревью владельца продукта ожидается. Применимость к выпущенной 3.4 не установлена. Раздел доступен отдельно и не включается автоматически в экспорт руководства; исходный код и неподтверждённые редакторские предложения не опубликованы.

## Что где хранится

| Каталог | Назначение |
| --- | --- |
| knowledge/en, knowledge/jp | Текст знаний без встроенных изображений |
| implementation/3.5.0-beta-build2422 | Проверенные по коду объяснения для одного beta-снимка, отдельные от пользовательского руководства и его экспорта |
| illustrations | Только текстовые задания на иллюстрации для User Guide: название, caption, что показать и место вставки |
| archive/site | 272 файла исходников сайта, включая оригинальные MDX; только историческое свидетельство, не активный AI-корпус |
| catalog | Источники, версии представления, проверки и история преобразования |
| schemas, tools | Схемы, валидация, правила версий и текстовый экспорт |
| entities, evals | Место для структурированных данных и вопросы для проверки ответов |
| examples | Внешние ссылки на существующие скачиваемые примеры |

Категории без исходных статей остаются подготовленными, но не заполняются вымышленными фактами. Задания на иллюстрации исключены из обычного AI-поиска.

## Скриншоты и GIF

Скриншот — материал для понимания. Из него нужно извлечь текст: состояние интерфейса, точные названия, действия, результат и ограничения. Если это достаточно описано словами, изображение не требуется.

Иллюстрации нужны только при подготовке User Guide. Для них достаточно текстового задания. Новая статья не обязана иметь ни изображение, ни задание на изображение.

Старые 786 мест иллюстраций сохранены как **необязательные черновики**, полученные из alt, заголовков и соседнего текста. Они не доказывают необходимость картинки и не являются результатом просмотра GIF. При редактуре оставляйте только полезные иллюстрации. Там, где информация была исключительно визуальной, текст ещё требует проверки; детали не выдуманы.

Подписи значимых inline-иконок сохранены текстом, повторяющие окружающее описание подписи убраны. История преобразования и исходные подписи доступны в catalog/text-only-conversion.json.

## Версии

Публичная версия — **3.4**, версия **3.5** разрабатывается. Применимость факта, статус его проверки и доступность релиза — разные признаки.

- **legacy-guide-3.4**: утверждённое текстовое представление существующего руководства, ограниченное точными хешами. Не означает проверку поведения в приложении.
- **verified-public**: только проверенные знания с явной применимостью. Пока нет независимо подтверждённых записей.
- **development-preview**: явно применимые знания для выбранной версии, включая черновики. Материалы 3.4 не наследуются в 3.5 автоматически.

Импортированные записи остаются in_review, с неизвестными проверенными границами применимости. Исторические release notes и юридические страницы помечены отдельно. Переводы не создавались и не объявлялись актуальными без проверки.

## Команды

Node.js >=22.13.0, pnpm 11.20.0.

~~~sh
pnpm install --frozen-lockfile
pnpm validate
pnpm test
pnpm export --profile legacy-guide-3.4 --version 3.4
pnpm export --profile legacy-guide-3.4 --version 3.4 --view user-guide
~~~

Первый экспорт создаёт текстовый корпус и JSONL-фрагменты для поиска. Второй добавляет в Markdown черновые места иллюстраций: название, caption и что показать. В обоих случаях файлы изображений не копируются; JSONL содержит только знания, без редакторских заданий.

Результаты создаются в отдельных каталогах dist/. Повторная запись в существующий результат запрещена: переместите предыдущий экспорт перед новой сборкой. При изменении статьи положения её иллюстраций требуют пересмотра; устаревшие задания блокируют экспорт User Guide.

Поддерживаются major.minor[.patch]. Для prerelease/build-зависимости и автоматических фильтров ОС/лицензий потребуется расширение схемы и проверок.

## Архив и восстановление

~~~sh
pnpm restore-source
~~~

Команда извлекает только **исходники** в .restored-site с проверкой SHA-256. Это не автономная рабочая копия сайта: public-ресурсы, зависимости и окружение не включены. Данные об исключённых ресурсах сохранены как provenance в catalog/external-resources.json. Прежняя проверка полного восстановления описана только в историческом отчёте; она не относится к текущему составу папки.

## GitHub и дальнейшая работа

Репозиторий: [FrontPictures/screenberry_knowledge_base](https://github.com/FrontPictures/screenberry_knowledge_base). Клонируйте его целиком, включая .github. Не включайте в коммиты node_modules, dist и .restored-site.

После принятия базы разработчиками редактируйте knowledge/ как основной источник знаний. Исходный сайт пока не подключён к этой базе автоматически. Архив не редактируется и не индексируется как вторая копия знаний.
